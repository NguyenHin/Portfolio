Building TotalEnglish – My First Flutter App

March 2025 · Flutter · Firebase

📌 Project Overview

TotalEnglish is a mobile application designed to help users learn English through vocabulary practice, speaking, and simple UI interactions. This project was built as part of my learning journey with Flutter.

🛠 Technologies Used

  • Flutter for UI development
  • Firebase Authentication
  • Firebase Firestore

🚧 Challenges

One of the biggest challenges was managing state and keeping data synchronized between the UI and Firebase.

🎯 What I Learned

  • Flutter widget lifecycle & layout system
  • Basic state management concepts
  • Designing clean and user-friendly UI
