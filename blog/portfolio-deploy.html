Deploying My Personal Portfolio Website

December 2024 · Portfolio · Deployment

📌 Overview

Building a personal portfolio website was an important step in my journey as a developer. It allowed me to showcase my projects, skills, and learning progress in a professional way.

🛠 Tools & Technologies

  • HTML, CSS, JavaScript
  • Responsive layout & dark theme
  • Git & GitHub
  • GitHub Pages for deployment

🚧 Challenges

The hardest part was making the layout responsive on different screen sizes and organizing content so it feels clean instead of crowded. I also learned how small UI details affect user experience.

🎯 What I Learned

  • How to structure a portfolio logically
  • Using GitHub Pages to deploy static websites
  • Improving UI/UX through spacing and typography
  • Thinking like a product owner, not just a coder

🚀 Deployment

After pushing the code to GitHub, I deployed the site using GitHub Pages. This helped me understand how hosting works and how to manage public projects.
